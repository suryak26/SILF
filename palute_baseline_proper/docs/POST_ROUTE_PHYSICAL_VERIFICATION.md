This document records the additional verification evidence established after completion of the PALUTE BL-00 physical-design flow.

## SPEF

Final file:

`flow/results/asap7/palute_lut_gen/base/6_final.spef`

The file begins with:

```
*SPEF "ieee 1481-1999"
*DESIGN "lut_gen_unit"
*VENDOR "The OpenROAD Project"
*PROGRAM "OpenROAD"
*VERSION "26Q3-2056-g41a28926b9"
*T_UNIT 1 NS
*C_UNIT 1 PF
*R_UNIT 1 OHM
```

The file contains `*NAME_MAP`, `*PORTS`, `*D_NET`, `*CONN`, `*CAP`, `*RES`, and `*END` sections.

Interpretation: the final routed design has explicit extracted resistance, capacitance, and coupling-capacitance data. SPEF is a post-route output, not a synthesis input. The available logs show RC extraction and SPEF generation but do not show a separate `read_spef` command.

The reported 2.50 mW VDD power value belongs to the power-grid/IR analysis context. It must not be substituted for the separate final cell-level power report, which reports 2.50 mW total power with internal, switching, and leakage components.

## Electromigration

No available BL-00 run artifact identified so far establishes an electromigration/current-density analysis. Therefore this baseline does not claim EM verification.

## Reproducibility note

The WSL run remains the source of truth for generated binary artifacts. This GitHub baseline snapshot records the verified results and the exact paths/names of generated artifacts. Generated ODB/GDS/SPEF binaries are intentionally not duplicated in this lightweight archival snapshot.
